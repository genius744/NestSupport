# Диагностика и устранение ошибок NeftSupport

## 1. Проблемы с правами доступа ERPNext

**Проблема:** при входе под учётной записью сотрудника возникало сообщение Not permitted.

**Причина:** недостаточные разрешения для работы с отдельными объектами ERPNext.

**Решение:**
- Проверены роли пользователя.
- Проверены разрешения для Issue.
- Настроены необходимые права чтения и создания обращений.
- Добавлены права чтения для Issue Priority и Issue Type.

**Результат:** сотрудник получил возможность создавать и просматривать обращения.

## 2. Проблема с отображением Frappe Wiki

**Проблема:** после установки Wiki приложение некорректно определялось в списке приложений сайта.

**Причина:** в файле sites/apps.txt отсутствовала корректная запись о приложении wiki.

**Решение:**
- Проверен каталог установленных приложений.
- Исправлен файл sites/apps.txt.
- Повторно проверены зависимости приложения.
- Проверена загрузка модуля Wiki.

**Результат:** Wiki успешно открывается по адресу /wiki-app.

## 3. Проблема с доступом пользователей к Wiki

**Проблема:** пользователи не имели необходимых возможностей для работы с базой знаний.

**Решение:**
- Добавлена роль Wiki User.
- Настроены разрешения пространства Wiki.
- Для сотрудников оставлен доступ на чтение.
- Для IT-специалистов настроено редактирование.
- Отключена возможность отправки предложений по редактированию для пользователей с доступом только на чтение.

**Результат:** разграничение доступа работает согласно назначенным ролям.

## 4. Отсутствие навигации из Wiki в ERPNext

**Проблема:** после перехода в Wiki пользователю приходилось использовать кнопку браузера «Назад», чтобы вернуться в ERPNext.

**Решение:**
- Изучена структура исходного кода Frappe Wiki.
- Найдены компоненты SpaceSidebar.vue и LibrarySidebar.vue.
- В обе боковые панели добавлена ссылка «Вернуться в ERPNext».
- Выполнена сборка frontend-приложения.
- Проверена работа ссылки.

**Результат:** пользователь может вернуться в ERPNext непосредственно из интерфейса Wiki.

## 5. Предупреждение при сборке frontend

**Проблема:** во время сборки frontend отображалось предупреждение о крупных JavaScript-файлах.

**Причина:** некоторые собранные файлы превышают рекомендуемый размер.

**Решение:** проверено завершение сборки и отсутствие критических ошибок.

**Результат:** сборка завершилась успешно. Предупреждение не препятствует работе приложения.
