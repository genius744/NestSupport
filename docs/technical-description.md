# Техническое описание NeftSupport

## 1. Общие сведения

NeftSupport — учебная информационная система, предназначенная для автоматизации процесса обработки обращений сотрудников в службу IT-поддержки.

Система построена на базе ERPNext 15 и Frappe Framework 15. Для организации базы знаний используется приложение Frappe Wiki.

## 2. Цель разработки

Цель проекта — создать программную модель службы технической поддержки предприятия, позволяющую регистрировать обращения, контролировать их выполнение и предоставлять сотрудникам инструкции по самостоятельному решению типовых проблем.

## 3. Пользователи системы

### Сотрудник (Employee)

- Создаёт обращения в службу IT-поддержки.
- Указывает тему и описание проблемы.
- Выбирает категорию обращения и приоритет.
- Просматривает состояние заявки.
- Ознакомляется с инструкциями в базе знаний.

### IT-специалист (Support Team)

- Просматривает поступившие обращения.
- Анализирует описание проблемы.
- Изменяет статус заявки.
- Добавляет информацию о выполненном решении.
- Редактирует статьи базы знаний.

## 4. Обработка обращений

Для регистрации обращений используется стандартный объект Issue платформы ERPNext.

Основные этапы обработки:

1. Сотрудник создаёт заявку.
2. Указывает категорию, приоритет и описание проблемы.
3. IT-специалист получает обращение.
4. Специалист анализирует проблему и выполняет необходимые действия.
5. Обновляет статус заявки.
6. Добавляет описание решения.
7. Обращение переводится в завершённое состояние.

Используемые статусы включают Open, Replied, On Hold, Resolved и Closed.

## 5. Категории обращений

В системе предусмотрены следующие категории:

- Компьютеры и оборудование.
- Программное обеспечение.
- Сеть и интернет.
- Принтеры и сканеры.
- Учётные записи и доступ.
- Электронная почта.

## 6. База знаний

Для хранения инструкций используется Frappe Wiki.

Создано пространство «База знаний NeftSupport», содержащее инструкции:

- Что делать, если не работает принтер.
- Что делать, если не работает интернет.
- Проблемы со входом в учётную запись.
- Как создать IT-заявку в NeftSupport.

Сотрудникам предоставлен доступ на чтение. IT-специалисты могут редактировать материалы.

## 7. Разграничение доступа

В системе используются отдельные роли для сотрудников и специалистов технической поддержки.

Доступ к функциям ERPNext и материалам Wiki настраивается с учётом роли пользователя.

Для Wiki отключена возможность отправки предложений по редактированию со стороны пользователей, имеющих только доступ на чтение.

## 8. Техническая среда

- Операционная система: Windows 11.
- Среда Linux: WSL2 Ubuntu 22.04.
- Контейнеризация: Docker Desktop.
- Среда разработки: Visual Studio Code.
- Платформа: ERPNext 15.
- Фреймворк: Frappe Framework 15.
- База знаний: Frappe Wiki версии 3.

## 10. Ограничения проекта

NeftSupport является учебной моделью. В нём используются тестовые учётные записи и демонстрационные обращения. Система не подключена к реальной инфраструктуре предприятия.
