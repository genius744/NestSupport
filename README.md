# NeftSupport

**NeftSupport** — учебная информационная система для организации IT-поддержки сотрудников предприятия.

## 1. Назначение проекта

Система предназначена для регистрации, обработки и контроля обращений сотрудников по вопросам работы офисной IT-инфраструктуры.

Проект моделирует работу службы технической поддержки и создан в образовательных целях.

## 2. Используемые технологии

- ERPNext 15
- Frappe Framework 15
- Frappe Wiki
- Docker
- WSL2 Ubuntu 22.04
- Git

## 3. Реализованные возможности

- Регистрация IT-заявок сотрудниками.
- Категоризация обращений.
- Установка приоритета заявки.
- Обработка обращений IT-специалистом.
- Изменение статусов заявок.
- Добавление информации о выполненном решении.
- База знаний с инструкциями для сотрудников.
- Разграничение прав доступа.
- Переход из Wiki обратно в ERPNext.

## 4. Категории обращений

- Компьютеры и оборудование.
- Программное обеспечение.
- Сеть и интернет.
- Принтеры и сканеры.
- Учётные записи и доступ.
- Электронная почта.

## 5. Структура репозитория

- `config/` — конфигурационные примеры.
- `patches/` — изменения исходного кода Wiki.
- `docs/` — документация и результаты тестирования.
- `README.md` — описание проекта.

## 6. Примечание

Проект является учебной моделью системы IT-поддержки. Он не использует реальные информационные системы или конфиденциальные данные предприятий.

Базы данных, резервные копии, пароли и персональные данные пользователей не включаются в данный репозиторий.
